Get to A - Maze Starter

ไฟล์ Java:
src/game/Main.java
src/game/GameFrame.java
src/game/Character.java
src/game/Player.java
src/game/MazeMap.java
src/game/PuzzleStation.java

วิธีรัน:
1. เปิดโฟลเดอร์โปรเจกต์ใน VS Code
2. ใช้ JDK ที่ติดตั้งไว้
3. Run Main.java
4. ใช้ W A S D เดิน

เงื่อนไข:
- ชนกำแพงไม่ได้
- จุดเริ่มคือ START
- จุดจบคือ EXIT
- ต้องใช้เวลาอย่างน้อย 20 วินาทีก่อนจบ Puzzle
- คะแนน Puzzle:
  <= 20 วินาที = 70
  21-30 วินาที = 65
  31-60 วินาที = 55
  > 60 วินาที = 45

หมายเหตุ:
โค้ดนี้เป็นเวอร์ชันเริ่มต้นสำหรับนำไปต่อกับโปรเจกต์ Get to A
