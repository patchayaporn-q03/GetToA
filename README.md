# วิ่งเก็บเกรด ( Get to A )

เกมแนว 2D ผู้เล่นควบคุมตัวละครเดินไปยังจุดที่กำหนดบนแผนที่ เพื่อไปแก้ปริศนา (Puzzle) มีทั้งหมด 2 ด่านโดยผลลัพธ์ของแต่ละด่านจะถูกแปลงเป็นเกรด (A/B/C/D/F) แทนคะแนนตัวเลข และมีการสุ่มเกรดตามการเปิดกกล่องที่กระจายอยู่ตามแผนที่
 
พัฒนาด้วยภาษา Java, ออกแบบ GUI ด้วย NetBeans GUI Builder , figma และเก็บข้อมูลด้วยไฟล์ CSV

## ฟังก์ชันการทำงานของโปรแกรม
 
### 1. หน้าจอ
1. **Loading Screen** — แสดงชื่อเกม + loddingขณะโหลด + ตัวละครเล็กๆ 1 ตัว ก่อนเข้าสู่เมนูหลัก
2. **Main Menu** — เริ่มเกม / แต่งตัวละคร / ออกจากเกม
3. **Character Customization** — เลือกตัวละคร และเพศของตัวละคร
4. **Game Map (Lobby/Start Point)** — ตัวละครปรากฏที่จุดเริ่มต้น รอเริ่มเดินสำรวจแผนที่
5. **Puzzle Station** — เมื่อเดินถึงจุดด่าน จะเข้าสู่หน้าต่างปริศนา (มีทั้งหมด 2 ด่าน)
6. **Result Screen** — สรุปเกรดรวมทุกด่านและเกรดสุดท้ายของผู้เล่น
### 2. ระบบหลัก
- **ระบบเลือกตัวละคร**: เลือกตัวละครก่อนเริ่มเล่น
- **ระบบเดิน/ควบคุม**: เคลื่อนที่ด้วย `W A S D`
- **ระบบกดทำเควส/เปิดกล่อง**: กด `E`
- **ระบบด่าน Puzzle + หัวใจ**: แต่ละด่านมี 3 หัวใจ ตอบ/แก้ผิดเสีย 1 หัวใจ
  - เสีย 0 ครั้ง (หัวใจครบ 3) → เกรด A
  - เสีย 1 ครั้ง → เกรด B
  - เสีย 2 ครั้ง → เกรด C
  - เสีย 3 ครั้ง (หัวใจหมด) → เกรด F
- **ระบบกล่องสุ่มเกรด**: ระหว่างทางในแมพจะมีกล่องตั้งอยู่ เลือกเปิดหรือไม่เปิดก็ได้ ถ้าเปิดจะสุ่มได้เกรด `A/B/C/D/F` เพิ่ม
- **โหมดผู้เล่น**: เล่นคนเดียว
### 3. การเก็บข้อมูล
- **GameFrame** เก็บข้อมูลแผนที่/ด่าน
- **PuzzleStation**: ข้อมูลภารกิจ
    - `puzzles.csv` เก็บข้อมูลว่าแต่ละด่านมีปริศนาอะไรบ้าง คำตอบคืออะไร และคะแนนที่จะได้
- **GradeManager**: บันทึกข้อมูล/ประวัติผู้เล่น
    - `player_save.csv` เก็บข้อมูลของผู้เล่นเอาไว้เพื่อให้ผู้เล่นสามารถย้อนดูได้
- **Character**: ตัวละครผู้เล่น
    - `character_stats.csv` เก็บข้อมูลตัวละครที่จะให้ผู้เล่นเลือก (เพศ/ตัวละคร) การเดินของตัวละคร หัวใจเริ่มต้นของตัวละคร
- **MainMenuScreen**: Lobby Setting
    - `settings.csv` เก็บข้อมูลการเลือกตัวละครของผู้เล่น

## ขอบเขต
- ภาษา: Java
- GUI: NetBeans GUI Builder (Java Swing) / Figma
- การเก็บข้อมูล: ไฟล์ CSV

## Class Diagram
คลาสหลัก ได้แก่ 
- `GameFrame` mapทั้งหมด
- `PuzzleStation` ด่านหลักที่จะเอาไว้ให้ทำภารกิจ รวมการเดินและการแก้ปริศนา
- `LoadingScreen` หน้าโหลดก่อนเข้าเกม
- `MainMenuScreen` lobby start game / เลือกตัวละคร
- `Character` ตัวละครผู้เล่น
- `Player` การควบคุมตัวละครของผู้เล่น
- `GradeBox` กล่องเก็บเกรดที่จะใช้สุ่มเมื่อผู้เล่นเปิด
- `HeartManager` จำนวนหัวใจสำหรับเล่นแดต่ละด่านในการแก้ puzzle
- `GradeManager` เกรดรวมสุดท้ายเมื่อผู้เล่นแก้ puzzle ครบ
- `ResultScreen` หน้าสรุปผล/เกรดสุดท้ายตอนจบเกม
- `DataGame` เก็บข้อมูลเกม จะแยกเก็บข้อมูลของแต่ละไฟล์
