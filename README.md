# วิ่งเก็บเกรด ( Get to A )

เกมแนว 2D ผู้เล่นควบคุมตัวละครเดินไปยังจุดที่กำหนดบนแผนที่ เพื่อไปแก้ปริศนา (Puzzle) มีทั้งหมด 2 ด่านโดยผลลัพธ์จะถูกคำนวณเป็นคะแนนเต็ม 100 (จากการเปิดกล่องสูงสุด 30 คะแนน + การแก้ปริศนา 70 คะแนน) แล้วแปลงเป็นเกรด (A/B/C/D/F)

## ฟังก์ชันการทำงานของโปรแกรม
 
### 1. หน้าจอ
1. **Loading Screen** — แสดงชื่อเกม + loadingขณะโหลด + ตัวละครเล็กๆ 1 ตัว ก่อนเข้าสู่เมนูหลัก
2. **Main Menu** — เริ่มเกม / แต่งตัวละคร / ออกจากเกม
3. **Character Customization** — เลือกตัวละคร และเพศของตัวละคร
4. **Game Map (Lobby/Start Point)** — ตัวละครปรากฏที่จุดเริ่มต้น รอเริ่มเดินสำรวจแผนที่
5. **Puzzle Station** — เมื่อเดินถึงจุดเล่นเกม ต้องกด`E`เพื่อเข้าสู่หน้าต่างปริศนา (แมพละ 1 เกม)
6. **Result Screen** — สรุปเกรดที่ได้จากการเดินเปิดกล่อง + การเล่นเกม
### 2. ระบบหลัก
- **ระบบเลือกตัวละคร**: เลือกตัวละครก่อนเริ่มเล่น
- **ระบบเดิน/ควบคุม**: เคลื่อนที่ด้วย `W A S D`
- **ระบบกดทำเควส/เปิดกล่อง**: กด `E`
- **ระบบด่าน Puzzle**: เกมแรกเป็นหาทางออกจากเขาวงกต เกมที่สองเป็นการต่อสายไฟทำให้ไฟในแมพสว่าง
    - คะแนนของ puzzle ด่านละ 35 คะแนนรวมเป็น70คะแนน
---
| เวลาที่ใช้ | คะแนนที่ได้ |
|---|---|
| ≤20 วินาที | 35 (เต็ม) |
| 21–30 วินาที | 25 |
| 31–60 วินาที | 15 |
| >60 วินาที | 5 |
---
- **ระบบกล่องสุ่มคะแนน**: ระหว่างทางในแมพจะมีกล่องตั้งอยู่ 6 กล่องเหมือนกันหมด ต้องเลือกเปิด3กล่องจากกล่องทั้งหมด โอกาสได้แต้มบวก (0–10) หรือ โดนหักแต้ม (-10) ถ้าเจอกล่องกับดัก
    - คะแนนการเปิดกล่อง รวม 30 คะแนน จะเป็นการเสี่ยงดวงว่ากล่องที่เปิดจะได้บวกคะแนนหรือโดนลบคะแนน
    - กล่องที่คะแนนติดลบจะมีแค่ 1 กล่องต่อ 1 แมพ
    - ถ้าเลือกกล่องครบ 3 กล่องแล้วกล่องทั้งหมดจะหายไปด้วย
- **โหมดผู้เล่น**: เล่นคนเดียว
### 3. การเก็บข้อมูล
- **PuzzleStation**: ข้อมูลภารกิจ
    - `puzzles.csv` เก็บข้อมูลเกม และคะแนนที่จะได้
- **GradeManager**: บันทึกคะแนนรวม/ผลลัพธ์ของผู้เล่น
    - `player_save.csv` เก็บคะแนนกล่อง, คะแนน puzzle, เกรดสุดท้ายของผู้เล่นแต่ละรอบ
- **Character**: ตัวละครผู้เล่น
    - `character_stats.csv` เก็บข้อมูลตัวละครที่จะให้ผู้เล่นเลือก (เพศ/ตัวละคร) การเดินของตัวละคร
- **MainMenuScreen**: Lobby Setting
    - `settings.csv` เก็บข้อมูลการเลือกตัวละครของผู้เล่น

## Class Diagram
คลาสหลัก ได้แก่ 
- `GameFrame` mapทั้งหมด
- `PuzzleStation` ด่านหลักที่จะเอาไว้ให้ทำภารกิจ รวมการเดินและการแก้ปริศนา
- `LoadingScreen` หน้าโหลดก่อนเข้าเกม
- `MainMenuScreen` Play/Avatar/Exit
- `CharacterSelect` เลือกเพศตัวละคร + เลือกแบบ 1 ใน 9 ตัวสำเร็จรูป + ปุ่มยืนยัน/ยกเลิก/ย้อนกลับ
- `Character` ตัวละครผู้เล่น
- `Player` การควบคุมตัวละครของผู้เล่น
- `GradeBox` กล่องเก็บคะแนนที่จะใช้สุ่มเมื่อผู้เล่นเปิด
- `GradeManager` รวมคะแนนจากกล่อง + puzzle แล้วคำนวนเป็นเกรดสุดท้ายเมื่อผู้เล่นเล่นครบ
- `ResultScreen` หน้าสรุปผล/เกรดสุดท้ายตอนจบเกม

โฟล์เดอร์เก็บไฟล์ข้อมูล
- `DataGame` เก็บข้อมูลเกม จะแยกเก็บข้อมูลของแต่ละไฟล์
